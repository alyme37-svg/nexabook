# NexaBook

A polished, interactive booking and client-management SaaS demo built with Next.js, TypeScript, Tailwind CSS, and Zustand.

Designed and developed by **Ali Elhussein** as a portfolio project.

**Live demo:** [nexabook-seven.vercel.app](https://nexabook-seven.vercel.app)

## Highlights

- Dashboard with derived business metrics and activity
- Booking management with conflict-aware availability
- Day, week, and month calendar experiences
- Client, team, and service management
- Public Luna Wellness booking flow
- Deterministic demo data with local persistence and reset
- Responsive layouts designed for desktop and mobile

## Run locally

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run lint
npm run typecheck
npm run build
```

Demo data is stored locally in each visitor's browser. No real customer data or authentication is used.
